# 🏥 Sistema de Gestión Hospitalaria - Base de Datos NoSQL y Análisis ML

Base de datos MongoDB y análisis de Machine Learning para el sistema de gestión hospitalaria.

## 📋 Descripción

Este repositorio contiene la base de datos NoSQL (MongoDB) y notebooks de análisis con Machine Learning para el proyecto de gestión hospitalaria.

## 🛠️ Tecnologías

- **MongoDB 7.0** - Base de datos NoSQL
- **Jupyter Lab** - Entorno de notebooks
- **Python 3.11** - Lenguaje de programación
- **Pandas** - Análisis de datos
- **Scikit-learn** - Machine Learning
- **Matplotlib/Seaborn** - Visualización
- **Docker Compose** - Orquestación de servicios

## 📊 Collections MongoDB

### 1. patient_histories
Historiales clínicos completos de pacientes con estructura flexible.

### 2. medical_analytics
Datos agregados y métricas para análisis y visualización.

### 3. ml_predictions
Resultados de modelos de Machine Learning y predicciones.

## 📓 Notebooks Jupyter

1. **01_data_exploration.ipynb** - Exploración inicial de datos
2. **02_patient_analysis.ipynb** - Análisis de patrones de pacientes
3. **03_disease_patterns.ipynb** - Análisis de enfermedades comunes
4. **04_prediction_model.ipynb** - Modelo predictivo de readmisiones
5. **05_clustering.ipynb** - Segmentación de pacientes
6. **06_anomaly_detection.ipynb** - Detección de anomalías

## 🤖 Modelos ML

- **Predicción de readmisiones** - Predice probabilidad de reingreso hospitalario
- **Clustering de pacientes** - Agrupa pacientes por características similares
- **Detección de anomalías** - Identifica patrones inusuales en diagnósticos
